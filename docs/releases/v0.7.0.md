## Highlights
- **Garmin watch app (Venu 3).** Read and answer your chats on the wrist: chat list with profile pictures, replies via AI suggestions or quick replies, adjustable font size, photos and video stills, emojis as smileys, voice messages transcribed automatically when you open a chat. Pair it with the six-digit code under Settings → Garmin watch. The app is sideloaded for now, see `garmin/README.md`.
- **Connections instead of storage locations.** Settings → "Connections" groups everything per provider: iCloud (mail, calendar, contacts) and your own server (Nextcloud, CalDAV/CardDAV, Immich) are set up separately.
- **Calendars and contacts.** iCloud and any CalDAV calendar can be the target for detected appointments; contacts come from iCloud or CardDAV, iCloud contacts without signing in again.
- **Glass look like Signal.** Chat list and chat header stay put with a frosted glass bar, search scrolls away, messages run underneath the header and the composer.
- **Link previews in bubbles**, YouTube with thumbnail, title and channel (only public addresses are fetched).

## Also since 0.6.1
- Keep view-once photos and videos and mark them (Signal/Telegram with image, WhatsApp as a note)
- Appointment detection: questions with a date count, all-day events, missing year added, date fallback when the AI finds nothing
- Signal watchdog reconnects after hangs or long silence instead of silently receiving nothing
- Keyboard on iPhone: no more white flash or wandering chat when focusing the input
- Attachment sheets (Immich, Nextcloud, GIF, editors, scheduling) are full screen again
- Live connection recovers after a server restart; faster gallery, receipts and search
- Auto-update keeps the log of the old container in `logs/`

## Upgrade
```bash
docker compose pull && docker compose up -d
```
With automatic updates set up, nothing to do.
